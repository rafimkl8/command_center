**Class variables vs instance attributes, `@staticmethod`, `@classmethod` (final, corrected version):**
> Class variables are the variables declared inside a class, outside any methods. You can change the value of any class variable using the class_name.class_variable_name. When you change it it will be changed for all the instances. But if you change it inside an instance, it will overshadow the class variable and use the assigned value from then on, because it creates an instance attribute with the class variable name, from then it's permanent, but it doesn't change other instances value for the class variable. Instance attribute is data set per object via self.name = value in __init__, it can be set independently per instance. @staticmethod is just a normal function, but it takes no self, no cls as a parameter, acts as a normal function with a def and normal parameters, mostly for calculation or anything logical purposes. @classmethod uses cls as the first parameter. cls refers to the class itself. Using the @classmethod, you can do both, read and write the class variables and also make another instance inside the class if needed.
