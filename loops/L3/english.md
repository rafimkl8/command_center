**Functions as objects, closures, and lambda (final, corrected version):**
> When you pass a function as a parameter to another function, it's called a higher-order function. You don't need parentheses in the def line. You can call them inside the function to show the result whenever needed. Only there you will need the parentheses. Because if you use parentheses in the def line it means call this immidietly, we don't want that. That's why we use it inside the function when needed to use the function variables. You can use a function inside another function by returning the function. But the main fact is, here the inner function remembers the value assigned from the outer function, even after the function calling is finished. This is called a closure. For the function division_maker, when we assign the value to 100 for the factor, it remembers, and when we call it separately to use it, the inside function divide_by remembers the assigned value of the factor and returns the result. When you call division_maker second time and assign the value 50 to a separate variable fifty, it creates a separate, independent memory; which you can use separately. Lambda is basically an one line function, no multi line logic or anything. One use of lambda is you declare a function using lambda n: n < 0 and assign the value to a variable is_negative. it works if you print it with print(is_negative(5)). Another use is if you have a list or tuple and you want an inline function to sort the items, you can use with a key, then the function, all in a single line. you don't need def for that.
