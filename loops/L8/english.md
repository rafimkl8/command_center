Polymorphism is something when we have many forms of the same method. It's the same call, same method name; but different behavior per object. Every call looks for each object's own class. abc is a python module, from that module we import ABC(abstract class) and @abstractmethod(a decorator). Abstract classes cannot be instantiated at all, never. You can instantiate a child class of the abstract class, only if you override the same method of the parent class in the child class. If it's not overridden, it will give error at the instantiation-time, not on definition-time.
