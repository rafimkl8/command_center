Inheritance is when a child class inherits from a parent class. It goes like this: class Alarm(Reminder). It automatically inherits everything from the parent class. But it can also have its own __init__ method with additional attributes which are not in the parent class's __init__. super().__init__ is used when you want to have the parent method __init__ to set up its attributes without retyping everything, after that its own attributes can be made and used along with the parent class's __init__ attributes. Method overriding works for a subclass defining its own version of the same method of the parent class. It doesn't modify any value of the parent class's method.
