Dunder stands for "double underscore". Dunder methods start and end with __. These methods are called implicitly, by Python itself. We don't have to call these methods separately, they work automatically. __str__ this one is used for printing any output. The values returned in this method get printed with the print function on the caller side. __repr__ it is the fallback whenever __str__ doesn't exist in the class. It shows how the data is presented in a raw code format. So, __str__ for readability and __repr__ for the developer/debugging. __eq__ this one checks equality among two values. It doesn't check where the values come from. Are they from different instances or different positions. It only checks if both the values are equal in their outputs, and returns true or false. __len__ this is used for holding a collection internally, it returns the total. You can call it using len(cart1). In these methods you never use print, only use return.
