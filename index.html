☁️ Set up cross-device sync (iPhone ⇄ Windows) — ~5 min, once

Your trackers save on each device by default. To sync them, connect a tiny free Firebase database. The web config is not a secret — your data is protected by your private sync code.

  1. Go to console.firebase.google.com → Add project (any name, e.g. "my-tracker"). Analytics optional.
  2. Build → Firestore Database → Create database. Choose Production mode, region asia-south1 (Mumbai, closest to Bangladesh).
  3. Open the Rules tab, replace everything with the rules below, and click Publish:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /trackers/{code} {
      allow read, write: if true;
    }
  }
}
  1. Click the gear icon → Project settings → Your apps → Web (</>). Register the app and copy the firebaseConfig values (apiKey, authDomain, projectId, appId).
  2. Paste those values into sync.js (the FIREBASE_CONFIG block at the top) — or just send them to your assistant to wire in and push.
  3. Open a tracker, tap Connect in the top bar, and set a sync code. Use the same code on your iPhone and laptop. Done — they now sync in real time. ✅
First-link tip: connect sync on your most up-to-date device first (it uploads), then connect the second device (it downloads & merges). After that, every tick syncs both ways automatically.
Privacy note: these rules let anyone who knows your exact sync code read/write that one document. For your personal study checkboxes that's fine — just keep your code private and make it long. (When you build your real full-stack capstone later, you'll add proper login.)

🌐 Hosting it so your iPhone can open it

To open these on your phone, host them free with GitHub Pages:

  1. On GitHub, open this repo → Settings → Pages.
  2. Under Source, pick Deploy from a branch → branch main → folder /(root) → Save.
  3. After a minute your site is live at https://rafimkl8.github.io/command_center/ — open that on your iPhone and laptop, and bookmark / add to home screen.
iPhone home-screen app: open the link in Safari → tap Share → Add to Home Screen. It opens fullscreen like a real app — no APK or App Store needed.
