## 🔁 How I use it

1. **Daily:** follow the routine (print version pinned at my desk); do the deep-work blocks.
2. **Per task:** tick things off in `weekly_tracker.html`.
3. **Weekly (Sunday):** review the 🔥 **Remaining** tab, clear red/essential items first, plan the next week.
4. **From Week ~22:** work the `career_launchpad.html` checklists (freelance → applications → interviews).
5. **On hard days:** re-read the 🔑 **Principles** tab.

---

## ☁️ Cross-device sync (iPhone ⇄ Windows)

The two trackers save locally by default and can sync in real time via a free Firebase project + a personal sync code. Full step-by-step setup is on the **hub page** (`index.html`).
